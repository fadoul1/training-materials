# GitHub Copilot in Practice

**Configure, Automate, and Extend Your AI Assistant**

Bienvenue dans cette formation de 5 jours pour maitriser GitHub Copilot au-dela des simples suggestions. Vous apprendrez a configurer, automatiser et etendre Copilot pour en faire un assistant de developpement precis, adapte a vos projets professionnels.

## Programme

| Jour | Module | Primitives | Duree |
|------|--------|------------|-------|
| 1 | [Comprendre Copilot et pourquoi la configuration compte](/modules/module-01) | Modele mental, contexte, tokens, 5 primitives | 1h 00m |
| 2 | [Custom Instructions et Prompt Files](/modules/module-02) | Primitive 1 : Always-On Instructions · Primitive 2 : File-Based Instructions · Primitive 3 : Prompt Files | 2h 30m |
| 3 | [Agent Skills : automatisation multi-etapes avec scripts](/modules/module-03) | Primitive 4 : Agent Skills | 1h 30m |
| 4 | [Custom Agents : personas specialisees avec scope controle](/modules/module-04) | Primitive 5 : Custom Agents | 1h 00m |
| 5 | [Workflow End-to-End et Projet Final](/modules/module-05) | Capstone guidé + projet libre + presentations | 2h 00m |

## Pre-requis

- Maitrise d'au moins un langage de programmation (C#, Java, Python, Node.js, etc.)
- Familiarite avec les workflows Git
- Licence GitHub Copilot valide
- Environnement de developpement configure avec VS Code et Copilot active
