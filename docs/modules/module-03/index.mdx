# Module 3 — Agent Skills et Custom Agents

**Duree : 2h 30m** | **Jour 3**

## Objectif

Packager des workflows automatises multi-etapes en skills que Copilot peut declencher sans prompting manuel, puis creer des personas IA specialisees avec un scope controle et la capacite d'orchestrer d'autres agents pour du travail multi-etapes.

---

## Partie 1 — Agent Skills (1h 30m)

### Theorie (30 min)

Un agent skill n'est pas un prompt. C'est un dossier contenant un fichier de description `SKILL.md`, des scripts et des ressources de support. Quand une tache correspond a la description du skill, Copilot active le skill, execute ses scripts et utilise la sortie structuree pour piloter l'action suivante.

Les skills sont un standard ouvert ([agentskills.io](https://agentskills.io)) qui fonctionne sur VS Code, le GitHub Copilot CLI et le GitHub Copilot coding agent.

#### Sujets couverts

- Structure de dossier d'un skill : `SKILL.md`, `scripts/`, `references/`, `assets/`
- Ecriture d'une description `SKILL.md` qui se declenche de maniere fiable
- Principes de conception de scripts : produire une sortie structuree (JSON ou texte)
- Comment l'agent lit la sortie du script et genere l'action suivante
- Reutilisabilite cross-tool : le meme skill dans VS Code, CLI et coding agent
- Extensions optionnelles : appels HTTP, lecture/ecriture de fichiers externes

## Partie 2 — Custom Agents (1h 00m)

### Theorie (30 min)

Un custom agent est une persona IA persistante definie dans un fichier Markdown. Il a son propre system prompt, son propre ensemble d'outils autorises, ses propres preferences de modele et ses propres limites de scope.

#### Concepts cles

- **Restrictions d'outils** — vous pouvez lister explicitement quels outils l'agent peut utiliser
- **Orchestration de sous-agents** — un agent peut deleguer une sous-tache a un autre agent specialise

#### Sujets couverts

- Structure Markdown d'un custom agent : frontmatter, system prompt, `tools`, `model`
- Comment ecrire un system prompt suffisamment specifique sans etre trop restrictif
- Restrictions explicites d'outils : pourquoi limiter les outils est une fonctionnalite
- Definition du scope : ce que l'agent doit faire et ce qu'il ne doit pas faire
- Orchestration de sous-agents : `delegate`, passage de contexte, reprise
- Archetypes d'agents : refactoring agent, migration agent, security audit agent
